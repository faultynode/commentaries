# Paragraph-by-Paragraph Comparative Commentary

## What this is, and what it is not

Two commentaries already exist. **Commentary P** treats the *read text* (P): the earlier work. **Commentary R** treats the *reading text* (R): a later work whose author made a close reading of P (Bernet on Husserl, Marion on Husserl and Heidegger, Henry on Husserl, Kojève on Hegel, and the like).

This run produces a third document: a close examination of the **relation** between R and P. It asks, unit by unit, what R does with P: which arguments it reconstructs, which it extends, which it re-describes in its own idiom, which it contests, and which it passes over.

This is **not** a synthesis run. Do not merge the two commentaries into a single account of "the matter itself," do not harmonize R and P into a composite doctrine, and do not let either author's voice absorb the other's. The object of commentary is the take-up, not the topic. Every sentence should be answerable to the question: *what is R doing with P here?*

## Inputs to confirm at the start of a run

If the request names a **run file**, read it first. It is authoritative for every input below, for the pair-specific notes, and for the progress marker. Repo-prefixed paths in it are resolved against whatever checkout layout the session has (sibling clones locally, added repositories in a cloud session); confirm where each repo is checked out before reading.

Otherwise, confirm only what is not inferable from the request or the files:

- **Commentary R** and **Commentary P** (paths).
- **The primary sources R and P** (paths), if available. The commentaries are maps; the sources are the authority.
- **Range** of R to cover (whole work, or specified Parts/chapters).
- **Editions and citation systems** of both texts, including the edition of P that R itself cites (which may differ from the edition Commentary P used).
- **Languages** of R, P, and any translation of P that R quotes from.

Absent other instruction, proceed on the defaults below: R's native unit governs; every unit treated at equal depth; claims about P verified against P; prose-only concise house style; a single growing file ending each turn at a clean structural boundary of R.

## Direction and unit of commentary

The reading text governs the order. Work through **R from beginning to end, every native unit in order** (use the same adaptive-unit rule as the base commentary skill: paragraph, numbered section, argumentative step in an unparagraphed lecture, and so on). Use Commentary R's unit divisions where they are sound, so the two documents stay aligned.

For each unit of R:

1. **State R's move** in your own words, briefly — Commentary R has already done the full reconstruction; do not redo it. One or two sentences that fix what R claims here.
2. **Locate the P-loci** the unit engages: explicit citations, quotations, paraphrases, and unacknowledged reliance on a P-doctrine. Give P's critical pagination.
3. **Return to P itself** at those loci, through Commentary P's treatment and then the source. State what P actually says there, in its own context and argumentative function.
4. **Characterize the take-up** (see the typology below) and say precisely where R departs from P: which distinction R keeps, which it collapses, which it adds; what P's argument was *for* and whether R's use preserves that function.
5. **Assess** the take-up locally: is R's reading supported by P's text, a defensible extrapolation, a productive misreading, or a misattribution? Ground the verdict in the P-locus, not in general sympathy for either author.

Units of R that cite nothing from P still receive full treatment. There the comparative work turns to **presupposition**: which P-doctrine the unit silently depends on, which P-material it prepares the ground to engage later, or what in P the passage conspicuously omits. If a unit is genuinely independent of P, say what R is building on its own account and how it will bear on R's later engagement with P. Never skip it.

## Typology of take-up

Classify each engagement, in prose, using these relations (a unit may show more than one):

- **Reconstruction**: R restates P's argument faithfully, perhaps in a sharper form.
- **Extension**: R carries a P-thesis into territory P did not reach, or draws a consequence P did not draw.
- **Radicalization**: R pushes a P-thesis past the limit P set for it, often turning P's own premise against P's conclusion.
- **Re-inscription**: R re-describes P's analysis in R's own vocabulary, so that a P-concept acquires a sense it did not have (watch for this most closely: it is where readings quietly become theses).
- **Contestation**: R argues that P is wrong, inconsistent, or self-undermining. State R's objection, then test it against P: does P have resources R ignores?
- **Selection and silence**: R isolates part of P's argument and leaves out what qualifies it. Name what is left out and whether it matters.
- **Mediation**: R reads P through an intermediary (an earlier commentator, a third author, a particular edition or translation). Name the intermediary and its effect.

The typology is a tool for seeing, not a grid to fill. Do not label units mechanically; name the relation where it sharpens the point.

## Verification rule

Claims about what P says must be checked against **P itself**, not taken from Commentary P alone. Commentary P is a reading too.

- Where R and Commentary P disagree about P, decide which is right *by the text of P*, and say so.
- Where R quotes P, check the quotation against the edition R cites and against the critical edition. Note omissions, ellipses that change sense, and emphasis R adds.
- Where R quotes P **in translation**, treat the translation as an interpretive act. Note renderings that already carry R's thesis (a French rendering of a Husserlian or Hegelian term that tilts it toward R's reading is a move, not a neutral medium).
- Where R used a **published translation that is not available** to the run, locate R's references by P's chapter and section, cite P by its original-language edition, and check R's quotations against the original only. Note divergences, but attribute a rendering to R's reading only when R's argument depends on it; otherwise it may be the translator's.
- Where Commentary R reports R's argument, check it against R's text as well.

## Chronology and corpus

Track **what R could have known of P**. R may have read P before later volumes, manuscripts, or lecture courses were published, or from an edition since superseded. Do not fault R for missing material not yet available. Do note where later-published P-material confirms, qualifies, or refutes R's reading, clearly marked as retrospective.

Track P's development where R treats P as a single position. If R reads a 1913 doctrine against a 1929 text, or reads early and late P as continuous, say so and state where the shift falls.

## Characteristic misreadings to guard against

Identify at the outset the standard traps of *this pair* (derive them from the two texts and their reception), state them briefly at the head of the file's first section, and guard against them throughout. If a run file is in use, record them under its **Pair-specific notes**. On later turns and sessions, read them from there rather than deriving them again; add a trap only when the text reveals a new one, and never silently reword an existing entry. In addition, these comparative traps apply to every pair:

- **Voice collapse**: attributing R's formulation to P because R presents it as exegesis, or attributing P's thesis to R because R reports it.
- **Retroactive reading**: understanding P through R's categories, so that R's reading appears confirmed by a P already reshaped in its image.
- **Commentary as source**: treating either commentary's interpretation as the text of P or R.
- **Disagreement as error**: assuming that where R departs from P, R has misread. Departure is often the point.
- **Agreement as fidelity**: assuming that where R's words match P's, R's use of them matches P's. Check the function, not only the wording.
- **Premature global verdict**: adjudicating "who is right" before the units have earned it. Verdicts are local until the end of a division.

## Headings

Reproduce **R's** structural divisions as headings, by the nesting rule of the base skill (H2 for the outermost reproduced division; H1 reserved for the document title). Translate headings into English if R is not in English. Do not reproduce P's divisions as headings; cite P's loci inline. Units carry no headings of their own; a plain lead-in is fine ("Bernet's second paragraph turns to Hua X §36…").

## Citation

Cite both texts by their standard scholarly systems throughout. R by its own pagination (or the critical pagination if it has one); P by its critical edition (Husserliana volume and page, GA volume and page, Akademie-Ausgabe, Bekker, Stephanus). Where R cites an older edition of P, give R's reference and the critical-edition equivalent once at first use of that locus, then use the critical form. Keep the format uniform: e.g. "R 112 / Hua X 368."

## Original-language terms and quotation

Apply the base skill's translation and term-retention rules to **both** texts. Keep one fixed glossary covering both authors, recorded under the run file's **Pair-specific notes** (retained terms, chosen English equivalents, and edition mappings once settled). Read it at the start of every turn and add to it only when a new term first occurs. Where R and P use the same term in different senses (or different terms for what R claims is the same thing), mark this the first time it occurs and hold the distinction steady: the divergence is often the substance of the take-up.

No bracketed original-language incipits. Short quotations from either text only where the exact wording carries the point (a contested rendering, a phrase R turns against P).

## House style

All house-style rules of the base skill apply: concise to the point of pressure; state the insight, do not narrate the reading; one pass per point; finite verbs over nominalizations; italics sparingly; prose only; no summary blocks at the start or end of the file.

Additional rules for this run:

- **Keep the two voices grammatically distinct.** Every claim has a subject: R, P, or the commentary. Never write "phenomenology shows" or "the analysis establishes" where you mean one author.
- **Lead with the departure.** The value of a unit is the precise point where R's use of P diverges from P's own. Put that first.
- **Do not re-summarize either commentary.** Draw on them; do not restate them.

## File segmentation (single growing file)

One file for the whole run: `<ShortTitleR>_on_<ShortTitleP>_Comparative_Commentary.md`, saved to the project's output folder (`/mnt/user-data/outputs/` in standard chat). Append continuously; stop only at a clean structural boundary of R; append to the same file on each later turn and re-present it.

## Workflow per turn

0. If a run file is in use, read it: inputs, pair-specific notes, and the **Progress** line. Resume from the unit after the last completed one, and check that the output file actually ends there; if they disagree, trust the output file and correct the Progress line.
1. Read the next range of R in Commentary R, and in R's source.
2. Collect every P-locus the range engages, explicit or implicit.
3. Read those loci in Commentary P and in P's source (`pdftotext`; rasterize with `pdftoppm` for headings, marginal pagination, or doubtful passages).
4. For each unit, fix R's move and P's text before drafting; draft the comparison from that, not from the commentaries' wording.
5. Append to the working copy of the file (recreate it from the saved version if missing).
6. End at a clean structural boundary of R.
7. Run the monolingual clarity pass and the concision-and-insight pass from the base skill, adding one test: in each paragraph, is it clear which author every claim belongs to?
8. Copy the updated file to the output folder and present it.
9. If a run file is in use, update its **Progress** line to the last completed unit (R's division and unit, with R's page), record any new pair-specific notes, and commit the output file and the run file together in one commit, then push. A turn is not finished until that commit is pushed.
10. If the output limit forced the stop, give a brief plain stopping-point note in chat and await "continue."

## At the close of each major division of R

After the last unit of each top-level division (Part, chapter, or equivalent), add one closing paragraph under the same heading (no new heading of its own) that states what R has done with P across that division: which P-arguments it has made load-bearing for its own project, where its reading holds against P's text, and where it does not. This is the only place for a cumulative verdict, and it must rest on the units just treated.
